# Range View Guest House Website

A full-stack guest house website and booking enquiry system developed using HTML, CSS, JavaScript, PHP and MySQL.

## Live Website

https://rangeviewguesthouse.infinityfree.io

## Project Overview

The Range View Guest House website was developed to provide visitors with information about the guest house, accommodation options, gallery images, contact details and an online booking enquiry system.

The project includes both a front-end interface and a PHP/MySQL back-end for storing booking enquiries.

## Features

- Responsive guest house website
- Home page with image slider
- Accommodation page
- Gallery page
- About Us page
- Contact Us form
- Multi-step booking enquiry process
- Arrival and checkout date selection
- Room selection
- Guest information collection
- Payment method selection
- Booking summary before submission
- PHP back-end processing
- MySQL database storage
- Live deployment using InfinityFree
