# Range View Guest House Website

A full-stack guest house website and booking enquiry system built using HTML, CSS, JavaScript, PHP and MySQL.

## Live Website

https://rangeviewguesthouse.infinityfree.io

## Features

- Home page with image slider
- Accommodation and gallery pages
- Contact form
- Multi-step booking enquiry system
- Guest information collection
- Payment method selection
- Booking summary
- MySQL database storage

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL / MariaDB
- XAMPP
- Visual Studio Code
- GitHub

## Setup

To run the project locally, place the project folder inside XAMPP's `htdocs` directory, start Apache and MySQL, and configure your own database connection using `db.example.php`.
